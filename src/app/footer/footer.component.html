Ecommerce

Este proyecto simula un Ecommerce desarrollado con fines de portafolio personal.

Esta desarrollado con Angular v19 con arquitectura standalone y programación reactiva con RxJS, aplicando buenas practicas como servicios facade, uso de Async pipe y enfocado a mobile first.

El maquetado se realizó con SCSS, siguiendo un diseño tomado de Figma, e integrando peticiones a una API REST (Fake Store API) para los productos y categorías, con foco en el aprendizaje y la correcta estructuración de una aplicación Front End.
